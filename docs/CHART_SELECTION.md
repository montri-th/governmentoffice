# กราฟเปรียบเทียบพื้นที่

ถาดกราฟด้านล่างแผนที่ (“เปรียบเทียบพื้นที่”) มีสามมุมมอง ใช้ข้อมูลชุดเดียวกับข้อค้นพบแรกและ choropleth คือ **scopeRows** (แถวตามตัวกรองค้นหา/หมวด/ประเภท/จังหวัด ก่อนเลือกพื้นที่) และมาตรวัดเดียวกับแผนที่ (หน่วยงาน หรือ บุคลากร) แท่งและช่องเป็นปุ่ม: ของเขต/อำเภอเปิดพื้นที่นั้น ของประเภทตั้งตัวกรองประเภทและเปิดบัตรประเภท กราฟวาดด้วย HTML ของเดโมเอง ไม่ใช้ไลบรารีกราฟ (`js/charts.js`, `js/chart-model.js`)

| มุมมอง (`?view=`) | คำถาม | การเข้ารหัส | ตัวชี้วัด | ขอบเขต |
|---|---|---|---|---|
| เขต/อำเภอ (`areas`, ค่าเริ่มต้น) | เขต/อำเภอไหนมีหน่วยงาน (หรือบุคลากร) มากที่สุด | แท่งแนวนอนเรียงลำดับ สีระดับเดียวกับแผนที่ (`count` หรือ `li.supply`) ตัวเลขอยู่นอกแท่ง ใต้ชื่อบอกจังหวัดและอีกมาตรวัดหนึ่ง | แห่ง หรือ คน | 20 เขต/อำเภอแรก |
| หมวด (`mix`) | เขตที่มีมากเป็นหน่วยงานหมวดใด | matrix เขต × หมวดที่มีในตัวกรอง ทุกช่องขนาดเท่ากัน สีช่อง = 41 ระดับตามลำดับค่าของช่องในตาราง หัวคอลัมน์มีรูปทรงของหมวด | แห่ง หรือ คน ต่อช่อง | 12 เขต/อำเภอแรก |
| ประเภท (`types`) | ประเภทใดมีหน่วยงาน (หรือบุคลากร) มากที่สุดในตัวกรองนี้ | แท่งแนวนอนสีพื้นฐานกลางเดียว (ประเภทไม่ใช่หมวดสีของแผนที่) พร้อมรูปทรงของหมวด ใต้ชื่อบอกอีกมาตรวัดหนึ่งและชื่อเต็มของประเภท | แห่ง หรือ คน | 20 ประเภทแรก |

## ความหมายของการเข้ารหัส

- **ความยาวแท่ง** เทียบกับค่าสูงสุดในกราฟ ตัวเลขจริงอยู่ข้างแท่งเสมอ ค่าเท่ากันเรียงตามอีกมาตรวัดหนึ่งแล้วตามชื่อ
- **Matrix ช่องเท่ากันทุกช่อง** ขนาดช่องไม่มีความหมาย ช่อง 0 คือ measured zero (ระดับ 0 + เส้นขอบศูนย์) ไม่ใช่ช่องว่าง ช่องที่ทุกแห่งไม่ทราบจำนวนบุคลากรเป็นขีด (ไม่ทราบ)
- **บุคลากรที่ไม่ทราบ** ไม่ถูกนับเป็น 0 คนในแท่งหรือช่องใด

## สีและระดับ

- หน่วยงานต่อพื้นที่: `count` (`4ff5c1fb…0980`) · บุคลากรที่บันทึกต่อพื้นที่: `li.supply` (Location Intelligence Profile, scaleVersion `671112f3…c497`) — ยอดรวม ไม่ใช่ความหนาแน่นหรือประชากรกลางวัน · ครบ 41 ระดับตามลำดับค่า (`js/scales.js#buildRamp`) สีเดียวกันทั้งสองธีม
- หมวด: categorical `landometer-series-10-v8` ผูกด้วย id พร้อมรูปทรงประจำ series ไม่ใช้ดาว
