## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** หน่วยงานรัฐและสถานที่ของชุดข้อมูลเดียวกัน (ทุกจุดของ production) กระจุกอยู่เขต/อำเภอใด มากแค่ไหนเมื่อเทียบกับทั้งจังหวัด ใกล้สถานีรถไฟฟ้าที่เปิดแล้วแค่ไหนเมื่อเทียบกับเขตอื่น (เมื่อจังหวัดมีสถานี) และนอกจังหวัดนั้นมีมากที่สุดที่ไหน ผู้ใช้เริ่มสำรวจระดับพื้นที่ได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot ข้อมูลสร้าง 6 พ.ย. 2569, รุ่น 0.4.0 — ทุกจุดของ production 440,005 จุด): **“17% ของหน่วยงานและสถานที่ในนครราชสีมา อยู่ใน 3 อำเภอนี้”** เมืองนครราชสีมา · ปักธงชัย · ด่านขุนทด — 3,466 จาก 20,003 แห่ง · ข้อค้นพบรอง “อันดับ 1 นอกนครราชสีมา: อำเภอเมืองเชียงราย เชียงราย 2,054 แห่ง · มากกว่าทุกอำเภอของนครราชสีมา” · ไม่มีแท่งรถไฟฟ้าเพราะนครราชสีมาไม่มีจุดใกล้สถานีที่เปิดแล้ว ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup · เลือกหมวด “หน่วยงานรัฐทุกหมวด” (`?group=offices`): “22% ของหน่วยงานรัฐในนครราชสีมา อยู่ใน 3 อำเภอนี้” เมืองนครราชสีมา · ปักธงชัย · สีคิ้ว — 165 จาก 744 แห่ง

แผนที่เปิดเป็นเมือง 3 มิติ (preset `city`, หรือ `plan` เมื่อ 3 อำเภออยู่ห่างกันเกิน 0.3°) ที่โฟกัส 3 อำเภอนั้นอัตโนมัติ (focus mode `auto`, URL ไม่มี `areas`): สี choropleth `count` สัญลักษณ์หน่วยงานตามหมวด (ขนาดตามบุคลากรที่บันทึก วงโปร่ง = ไม่ทราบ) สถานีรถไฟฟ้าเป็นวงกลมเงียบ และมวลอาคารมุมโค้งเฉพาะในโฟกัส ส่วนอื่นของเมืองเป็นบริบทที่เงียบ

**One useful action:** “ดูทุกพื้นที่” (`?areas=all`) และ “เปรียบเทียบพื้นที่” (เปิดกราฟ) · สลับ “หน่วยงานและสถานที่ | บุคลากร” ในคำอธิบายแผนที่: ข้อค้นพบเปลี่ยนเป็น “66% ของบุคลากรที่บันทึกในชลบุรี อยู่ใน 3 อำเภอนี้” (เมืองชลบุรี · ศรีราชา · สัตหีบ — 14,314 จาก 21,533 คน) · เลือกประเภท “สถานีตำรวจ”: “15% ของสถานีตำรวจในกรุงเทพมหานคร อยู่ใน 3 เขตนี้” พร้อมแท่งใกล้รถไฟฟ้า 3 เขตนี้ 8% (1/13) · เขตอื่น 27% (20/73)

## Evidence cue and calculation

แหล่ง: `data/offices.json` (หน่วยงานรัฐ 20,568 แห่ง; 535,745 คนจาก 10,095 แห่งที่บันทึกบุคลากร) + `data/groups/{education,religion,community}.json` (สถานที่ 419,437 แห่ง) = 440,005 จุดของ production และ `data/area-index.json` (928 เขต/อำเภอ) การคำนวณ: `summarizeAreaInsight` (`js/area-insight.js`) บนแถวที่ผ่าน `filterRows`

| อำเภอ | รหัส | หน่วยงานและสถานที่ | หน่วยงานรัฐ |
|---|---|---:|---:|
| เมืองนครราชสีมา | `3001` | 1,185 | 74 |
| ปักธงชัย | `3014` | 1,150 | 47 |
| ด่านขุนทด | `3008` | 1,131 | — |
| สีคิ้ว | `3020` | — | 44 |

จังหวัดที่นำ = จังหวัดที่มีจุดที่ระบุเขต/อำเภอได้มากที่สุด (นครราชสีมา 20,003 แห่ง; หน่วยงานรัฐ 744 แห่ง) สัดส่วน = 3,466 ÷ 20,003 = 17% (หน่วยงานรัฐ 165 ÷ 744 = 22%) ทุกแถวระบุเขตตามตำบลใน overlay ของ production ตัวหารจึงเท่ากับยอดทั้งจังหวัด สัดส่วนใกล้รถไฟฟ้านับเฉพาะจุดที่มีพิกัด ฐานทั้งสองฝั่งอยู่ในคำอธิบายของแท่ง

**ไม่ตัดผ่านค่าเท่ากัน และไม่โฟกัสทุกเขต:** ถ้าเขตลำดับถัดไปมีค่าเท่ากับเขตสุดท้ายที่แสดง โฟกัสเหลือเฉพาะเขตที่มากกว่า ถ้าทุกเขตเท่ากันข้อค้นพบเปลี่ยนเป็น “กระจาย” จังหวัดที่มีเขตที่มีค่าไม่เกิน 3 เขตโฟกัสเฉพาะ N − 1 เขตบนสุด

## States

| State | ผลบนหน้าจอ |
|---|---|
| โหลด | การ์ดเปิดเว็บ (`js/launch.js`) จนทุกไฟล์พร้อม: “กำลังโหลดหน่วยงานและสถานที่ 440,005 แห่ง · N จาก 3 หมวด”; ไฟล์ใดโหลดไม่สำเร็จ = การ์ดบอกพร้อมปุ่มลองใหม่ (ไม่แสดงหน้าแรกจากข้อมูลไม่ครบ) |
| จุดนอกโฟกัส | ทุกจุดของขอบเขตเป็นจุดสีเทาเงียบ ส่งให้แผนที่หลังภาพแรก (สีพื้นที่และสัญลักษณ์ในโฟกัสขึ้นก่อน) |
| ไม่พบตามตัวกรอง | “ไม่พบหน่วยงานและสถานที่ตามตัวกรองนี้” (หรือ “หน่วยงาน” / “สถานที่” ตามหมวด) + ล้างตัวกรอง |
| เขตที่ไม่มีหน่วยงานตามตัวกรอง | measured zero ของชุดข้อมูลนี้ + “ดูพื้นที่ที่พบ” |
| ไม่ทราบจำนวนบุคลากร | นับเป็นแห่ง ไม่นับเป็น 0 คน; ช่องตัวเลข “—”; เขตที่ไม่ทราบทั้งหมดเป็นลายทแยง (no data); สัญลักษณ์วงโปร่ง |
| บุคลากรนับที่อีกจุด | ชิป “N คน · นับที่อีกจุด” กดแล้วเปิดจุดที่นับ |
| สำนักงานใหญ่ | ชิป “ทั้งหน่วยงาน N คน” ไม่รวมเข้ายอดพื้นที่ |
| หมวดที่ไม่มีบุคลากร | ปุ่ม “บุคลากร” ปิด พร้อมคำอธิบายในชื่อปุ่ม; สถานที่ไม่มีแท่งหรือคอลัมน์บุคลากร และไม่เป็น “ไม่ทราบ” |
| แผนที่โหลดไม่ได้ | ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ พร้อมปุ่มลองใหม่ |
| ขอบเขตจังหวัดโหลดไม่ได้ | รายงานและลองใหม่เมื่อขอครั้งถัดไป แผงไม่พึ่งขอบเขต |
| เลือกหน่วยงานที่มีพิกัด | แผนที่เปลี่ยนเป็น 3 มิติ กล้อง 2-point ที่อาคารที่หมุดอยู่ในขอบ (“อาคารที่หมุดตก”) |
| หมุดไม่อยู่ในขอบอาคาร | กล้อง 2-point ที่อาคารใกล้หมุดที่สุดภายใน 300 ม. (ไม่มีก็โหลดถึง 800 ม.) หมุดอยู่ในภาพ ป้าย “อาคารใกล้หมุด” — ไม่นับใน “หน่วยงานในอาคารนี้” |
| ไม่มีอาคารบนแผนที่ในระยะ 800 ม. | กล้อง 2-point ที่พื้นที่รอบหมุด (กล่อง 90 ม.) |
| หน่วยงานที่ย้ายแล้ว | กล่อง “ย้ายที่ตั้ง · <วันที่>” ที่ตั้งใหม่ ที่ตั้งเดิม และประกาศ ก่อนตัวเลข |
